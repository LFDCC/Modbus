## ConsoleApp1 第 84 行报错根因（用户问：是否因 .NET 6）
- 报错 `CS8936: 功能“异步方法和迭代器方法中的 ref 和 unsafe”在 C# 10.0 中不可用，请使用语言版本 13.0+`。**本质确实是 net6.0 默认语言版本 C# 10 的限制**，不是 API 缺失。
- 机理：`res.Data.Span` 返回 `ReadOnlySpan<byte>`（ref struct）；`var span = res.Data.Span;` 在 async 方法内声明命名 ref-struct 局部 → C# 10 禁止（ref struct 不能进异步状态机），C# 13.0 才放开。
- 二次坑：`ReadValue<ushort>(EndianType.Big)` 扩展要求 `ref ReadOnlySpan<byte>`，内联 `res.Data.Span.ReadValue(...)` 会触发 `CS0206`（非引用返回属性不能作 ref 参数）。故 C# 10 下两条路都不通。
- 最终修复：`ConsoleApp1/ConsoleApp1.csproj` 加 `<LangVersion>13.0</LangVersion>`（本机 SDK 10.0.301 支持，对 net6.0 运行时无副作用），保留原写法 `var span = res.Data.Span; Console.WriteLine(span.ReadValue<ushort>(EndianType.Big));`。验证：`dotnet build Modbus.sln -c Release` → 0 警告 0 错误；`dotnet test` → 2/2 通过。
- 验证：`dotnet build Modbus.sln -c Release` → 0 警告 0 错误；`dotnet test Modbus.UnitTests` → 2/2 通过；`Samples` 真实运行 loopback 输出 `11,22,999,44,100,200,111,222` 正确。临时探针 `C:\Users\yanqi\probe_ext` 已用 `os.remove`/`os.rmdir` 递归删除。
