## AccessViolationException 根因定位（IL 反汇编 + 复现）
- 通过反射探针反汇编 TouchSocket 4.2.18 的 `TouchSocketBitConverter.To<T>` 方法 IL
- **调用链**：`To<T>(ReadOnlySpan<byte>)` -> 按 `sizeof(T)` 分发 -> `ByteTransDataFormat2/4/8/16_Net6(byte*)` 私有方法
- **根因**：`ByteTransDataFormat*_Net6(byte*)` 接收 raw `byte*` 指针，内部用指针偏移读写值。`To<T>` 从 span ref 转 `byte*` 传入时，若底层是非 pinned 托管数组，指针可能失效
- **复现**：`TouchSocketBitConverter.BigEndian.To<ushort>(new byte[] {0x12, 0x34})` 直接 segfault（exit code 139），try-catch 无法捕获
- **影响范围**：所有 T 类型均触发（ushort/short/uint/int/float/long/ulong/double），`ToValues<T>` 内部委托 `To<T>` 同样 AV
- **安全方法**：`GetBytes<T>` 不走指针路径，安全可用
- 项目已用 BCL `BinaryPrimitives` + `EndianType` 枚举替代，完全避开此问题
